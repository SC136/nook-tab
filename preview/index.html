Use it as your new tab

Try it on the web first. To make it open on every new tab, install the extension.

  1. Get the extension. Download the zip from the GitHub repository and unzip it somewhere you'll keep it.
  2. Load it in Chrome, Edge, Brave or Opera. Open chrome://extensions, turn on Developer mode, click Load unpacked and choose the folder with manifest.json.
  3. Or in Firefox. Open about:debugging, choose This Firefox, then Load Temporary Add-on and pick manifest.json.
  4. Make it yours. Click Customise in the top-right corner to change the theme, accent and background. Click Layout to move things around.
